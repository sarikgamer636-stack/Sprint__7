Что проверяется:
1. Создание курьера POST /api/v1/courier

1. Курьера можно создать
2. Нельзя создать двух одинаковых курьеров
3. Для создания нужны обязательные поля
4. Успешный запрос возвращает код 201 и {"ok": true}
5. Если одного из полей нет, возвращается ошибка 400
6. Если логин уже занят, возвращается ошибка 409

2. Логин курьера POST /api/v1/courier/login

1. Курьер может авторизоваться
2. Для авторизации нужны обязательные поля
3. Неверный логин или пароль возвращают ошибку
4. Отсутствие поля возвращает ошибку
5. Авторизация под несуществующим пользователем возвращает ошибку
6. Успешный запрос возвращает id

3. Создание заказа POST /api/v1/orders
Параметризованный тест:
1. Можно указать цвет BLACK или GREY
2. Можно указать оба цвета
3. Можно не указывать цвет
4. Тело ответа содержит track

4. Список заказов GET /api/v1/orders

1. В теле ответа возвращается список заказов
